# 크롬 웹스토어 제출 메모

심사에서 묻는 항목과 우리 답을 미리 적어 둔다. 매번 다시 쓰면 말이 달라진다.

패키지는 이렇게 만든다 — `node_modules`·`test`·`docs`·`tools`와 개발용 파일은 뺀다.
지금 기준 12개 파일 44KB.

## 단일 목적 (Single purpose)

> 스트리밍 사이트가 이미 내려주는 자막 트랙을 읽어, 사용자가 고른 두 언어를
> 영상 위에 함께 표시한다.

배속 조절도 같은 목적 안에 있다 — 언어 학습용으로 느리게/빠르게 보기 위한 것이고,
자막 표시와 같은 화면에서 같은 영상에 걸린다.

## 권한을 쓰는 이유

| 권한 | 이유 |
|---|---|
| `storage` | 글자 크기·색·위치·싱크 같은 사용자 설정을 기기에 저장한다. 서버로 보내지 않는다. |
| `scripting` | 페이지를 새로고침하지 않고도 이미 열려 있는 탭에 자막 표시를 적용하기 위해서다. 팝업의 "이 탭에 지금 적용하기" 버튼이 쓴다. |
| 호스트 권한 | 자막 트랙 목록과 자막 파일을 읽어야 한다. 넷플릭스·디즈니+·티빙·웨이브 본체와, 이들이 자막을 내려주는 CDN 도메인이다. |

CDN 도메인(`cloudfront.net`, `akamaized.net` 등)이 넓어 보이는데, 자막 파일이
그 위에서 배포되기 때문이다. 자막으로 보이는 응답만 읽고 나머지는 건드리지 않는다.

## 원격 코드

쓰지 않는다. 모든 스크립트가 패키지 안에 있다. 웹폰트도 받아오지 않는다.

## 데이터 취급

- 수집하지 않는다. 서버가 없다.
- 설정은 `chrome.storage.local` 에만 저장된다. 동기화도 하지 않는다.
- 자막 내용은 메모리에만 두고, 사용자가 직접 "`.srt` 로 저장"을 누를 때만 파일로 내린다.
- 분석·광고·추적 도구를 넣지 않는다.

## 심사에서 걸릴 수 있는 것

**`.srt` 로 저장.** 이 기능은 서비스가 내려준 자막을 파일로 뽑는다. 심사자가
"콘텐츠 추출"로 볼 여지가 있고, 각 서비스 이용약관과도 부딪힐 수 있다.
원래 목적은 같은 사람이 자기 안드로이드 오버레이 앱에서 쓰려는 것이지만,
심사에서 문제가 되면 이 기능만 빼고 다시 올리는 편이 빠르다.

**DRM 은 건드리지 않는다.** 영상·음성은 암호화돼 있고 우리는 손대지 않는다.
자막은 평문으로 내려오는 것을 그대로 읽는다. 설명에 이 점을 분명히 적는다.

**설명에 서비스 이름을 쓰는 것.** 상표를 로고·아이콘에 쓰지 않는다.
"넷플릭스에서 동작한다"처럼 사실을 적는 것은 문제가 없지만,
공식 제휴처럼 보이는 표현은 피한다.

- 언어: 한국어
- 스크린샷 1280×800 (최소 1장, 최대 5장) — **실제 작품 화면을 쓰지 않는다.**
  저작물이 그대로 들어가면 그것대로 문제가 된다. 팝업 화면과, 저작권 없는
  영상 위에 자막을 얹은 화면을 쓴다.
