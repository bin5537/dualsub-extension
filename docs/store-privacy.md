# 개인 정보 보호 관행 탭 입력값

스토어 폼의 "개인 정보 보호 관행" 탭에서 묻는 항목들. 그대로 붙여 넣는다.

---

## 단일 목적 (Single purpose)

```
스트리밍 서비스에 이미 등록되어 있는 자막을 읽어, 사용자가 선택한 두 개
이상의 언어를 영상 위에 동시에 표시합니다. 자막 표시에 딸린 배속·싱크·
글자 모양 조절도 같은 화면의 같은 영상에 적용되는 보조 기능입니다.
```

## storage 권한

```
사용자가 설정한 자막 글자 크기, 색상, 글꼴, 위치, 싱크 보정값, 재생 속도,
표시할 자막 언어를 저장하는 데 사용합니다. 다음에 영상을 볼 때 같은 설정을
그대로 적용하기 위한 것이며, chrome.storage.local 에만 저장하고 외부로
전송하지 않습니다.
```

## scripting 권한

```
확장을 설치하거나 업데이트한 직후에는 이미 열려 있는 탭에 콘텐츠 스크립트가
들어가 있지 않습니다. 이때 사용자가 팝업의 '이 탭에 지금 적용하기' 버튼을
누르면 현재 탭에 스크립트를 넣어, 페이지를 새로고침하지 않고도 자막을 표시할
수 있게 합니다. 사용자가 직접 누를 때만 실행됩니다.
```

## 호스트 권한

```
자막을 표시하려면 플레이어가 내려받는 자막 트랙 목록과 자막 파일을 읽어야
합니다. 대상은 지원 서비스의 재생 페이지(netflix.com, disneyplus.com,
tving.com, wavve.com)와, 이들이 자막 파일을 실제로 배포하는 CDN 도메인
(nflxvideo.net, dssott.com, bamgrid.com, cloudfront.net, akamaized.net 등)
입니다.

CDN 도메인이 넓어 보이지만 자막 파일이 그 위에서 배포되기 때문이며, 자막
형식(WebVTT, TTML, SRT)으로 판별되는 응답만 읽고 나머지 요청은 변경하거나
저장하지 않습니다. 영상·음성 스트림은 다루지 않습니다.
```

## 원격 코드 사용

**"아니요, 원격 코드를 사용하지 않습니다"** 를 선택한다.

이유를 적는 칸이 나오면:

```
모든 스크립트가 확장 패키지 안에 포함되어 있습니다. 외부에서 코드를
불러오거나 eval 로 실행하는 부분이 없으며, 웹폰트도 내려받지 않습니다.
```

## 데이터 사용 인증 (체크박스 3개)

세 항목 모두 체크한다. 우리는 데이터를 수집하지 않으므로 모두 사실이다.

- 승인된 사용 사례를 위해서만 데이터를 사용합니다
- 데이터를 승인되지 않은 제3자에게 판매하거나 양도하지 않습니다
- 신용도 산정이나 대출 목적으로 데이터를 사용하지 않습니다

## 데이터 유형 (수집 항목 선택)

**아무것도 선택하지 않는다.** 서버가 없어 수집할 방법 자체가 없다.

---

## 폼 밖에서 해야 하는 것

**설정 페이지 → 게시자 연락처 이메일**

이메일을 입력하고 인증 메일을 받아 확인해야 게시가 된다. 이 주소는 스토어에
공개되므로, 개인 메일을 그대로 쓰기 싫으면 따로 만드는 편이 낫다.

**임시저장**

등록정보 탭의 값(설명·언어·카테고리·아이콘·스크린샷)은 임시저장을 눌러야
반영된다. 누르기 전에는 입력해 두어도 "누락되었습니다"로 표시된다.
