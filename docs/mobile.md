# 모바일에서 쓰기

크롬 확장은 PC 크롬에서만 도는 게 아니다. 안드로이드는 오늘 바로 되고,
아이폰은 브라우저를 바꾸거나 사파리용으로 포팅해야 한다.

저장소 폴더를 그대로 zip 으로 묶어 쓴다 (`node_modules` 는 뺀다).

---

## 안드로이드 — 바로 가능

크롬 안드로이드는 확장을 지원하지 않지만, 같은 크로미움 기반의 다른 브라우저는 지원한다.

### 쓸 수 있는 브라우저

| 브라우저 | 비고 |
|---|---|
| **Lemur Browser** | 확장 지원, 플레이스토어에 있음. 현재 가장 무난함 |
| **Mises Browser** | 확장 지원, 압축 파일 직접 설치 가능 |
| ~~Kiwi Browser~~ | 2024년 말 개발 중단 — 권하지 않음 |
| Firefox | 확장 지원하지만 서명이 필요하고, 이 확장이 쓰는 MAIN 월드 주입 방식과 궁합이 나쁘다 |

### 설치 순서

1. 플레이스토어에서 **Lemur Browser** 설치
2. `DualSub-extension.zip` 을 폰으로 옮긴다 (카톡 나에게 보내기 / 드라이브 / USB)
3. 브라우저 메뉴 → **확장 프로그램** → **개발자 모드** 켜기
4. **압축 파일에서 로드** → 옮겨둔 zip 선택
5. 넷플릭스·티빙 등을 브라우저에서 열고 재생

### 모바일에서 주의할 점

- 사이트가 앱으로 유도하면 브라우저 메뉴에서 **데스크톱 사이트 요청**을 켜면 된다.
- 전체화면으로 보면 자막 위치가 어긋날 수 있다 — 팝업의 **높이** 값으로 맞춘다.
- 화면이 좁으니 **크기**와 **최대폭**을 PC와 다르게 잡는 게 낫다.

## 아이폰 — 두 가지 길

### 1. Orion 브라우저 (맥 없이 가능)

Kagi 가 만든 iOS 브라우저로, **크롬 확장을 설치할 수 있다.**
다만 웹스토어를 거치는 방식이라 이 확장을 **크롬 웹스토어에 올려야** 한다
(개발자 등록비 1회 $5, 비공개 링크 배포 가능).

### 2. 사파리 웹 확장으로 포팅

사파리도 iOS 15부터 웹 확장을 지원한다. 코드는 거의 그대로 쓸 수 있지만:

- **맥 + Xcode 필요** — 윈도우에서는 빌드 자체가 불가능
- 앱스토어 배포하려면 애플 개발자 계정 (연 $99)
- 본인 기기에만 넣는다면 계정 없이 7일마다 재설치하는 방법도 있다

윈도우만 있는 지금 환경에서는 1번이 현실적이다.

| 환경 | 방법 | 지금 가능? |
