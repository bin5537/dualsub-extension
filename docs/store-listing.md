폼에 그대로 붙여 넣을 문구.

---

## 패키지 제목

```
겹자막
```

## 패키지 요약 (132자 이내)

```
넷플릭스·디즈니+·티빙에 등록된 자막을 두 언어로 동시에 표시합니다.
```

## 설명

```
겹자막은 스트리밍 서비스가 제공하는 자막을 두 언어로 동시에 표시하는
크롬 확장 프로그램입니다.

대부분의 플레이어는 자막을 한 번에 하나만 켤 수 있습니다. 겹자막은 여기에
두 번째 자막을 더해 원어와 번역을 나란히 보여줍니다. 별도의 자막 파일을
준비할 필요 없이, 서비스에 이미 등록된 자막을 그대로 사용합니다.

외국어 학습, 원문 대조, 청취 연습에 활용할 수 있습니다.


지원 서비스

  넷플릭스, 디즈니+, 티빙, 웨이브


주요 기능

  이중 자막      원어와 번역을 동시에 표시합니다. 최대 3개 언어까지
                 선택할 수 있습니다.

  재생 속도      0.25배에서 4배까지 조절합니다. 자체 배속 기능이 없는
                 플레이어에서도 동작합니다.

  자막 싱크      0.5초 단위로 앞뒤 조정이 가능합니다.

  표시 설정      글자 크기, 색상, 글꼴, 굵기, 외곽선, 배경, 자간, 행간을
                 조절할 수 있습니다. 위치는 Alt 키를 누른 채 드래그하여
                 옮깁니다.

  자막 파일      보유한 .srt 또는 .vtt 파일을 직접 불러올 수 있습니다.

  단축키         Shift + ← →   자막 싱크
                 Shift + ↑ ↓   글자 크기
                 Shift + , .   재생 속도
                 Alt + 드래그   자막 위치


동작 방식

플레이어가 자막을 내려받을 때 해당 응답을 함께 읽어 화면에 표시합니다.
영상과 음성은 암호화되어 있으나 자막은 평문으로 전송되며, 겹자막은 이를
그대로 활용합니다. 콘텐츠 보호 기술을 우회하거나 변경하지 않습니다.


개인정보 보호

  사용자 데이터를 수집하지 않습니다.
  설정값은 브라우저 로컬 저장소에만 보관되며 외부로 전송되지 않습니다.
  분석 및 광고 도구를 포함하지 않습니다.


참고 사항

서비스에 등록되지 않은 언어는 표시할 수 없습니다. 서비스의 자막 전송
방식이 변경될 경우 일시적으로 자막을 인식하지 못할 수 있으며, 이 경우
팝업 하단의 '감지된 자막 후보'에서 확인된 정보를 전달해 주시면 대응합니다.
티빙과 웨이브는 실제 전송 구조 확인이 진행 중입니다.
```
